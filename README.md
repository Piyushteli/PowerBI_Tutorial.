# Power BI Tutorial

# Overview
The Power BI Tutorial folder contains two comprehensive resources:

1. Power BI Folder: Covers a wide range of Power BI topics, including:
    - Calculate DAX Formula
    - Card and Multi-row card visuals
    - Charts (Column, Line, and more)
    - Column Chart Formatting
    - Data Transformation
    - DAX Formulas (SUM, SUMX, and more)
    - Line and Clustered Column Chart
    - Gauge and KPI Charts
    - Date Between DAX formula
    - Maps
    - Slicers
    - Table and Matrix visuals
2. Order Data Folder: Month-wise order data in Excel files for hands-on practice and analysis.

# Contents
- Power BI Folder: In-depth tutorials and examples for mastering Power BI
- Order Data Folder: Real-world order data for practical application and learning

# Purpose
This repository provides a thorough learning experience for Power BI, covering key topics and DAX queries, along with practical data for hands-on practice.
